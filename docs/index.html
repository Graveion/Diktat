Get started on your Mac

curl -fsSL https://graveion.github.io/Diktat/install.sh | bash
1

Install

Run the command above. Everything Diktat needs is set up for you, including the diktat command.

2

Set up

Run diktat setup to detect your CLIs and choose which projects to expose.

3

Pair

Run diktat pair to show a QR. In the app, tap Pair a machine and scan it.

4

Go

Run diktat start. Open the app, pick your Mac, start coding from your phone.

Made for macOS. Use the coding-agent logins already on your machine. Diktat just hands you the remote.
